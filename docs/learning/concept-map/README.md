## Prerequisites and candidate jobs

The 56 candidates contain **44 algorithm concepts and 12 foundational concepts**. Coverage is classified as 42 with existing material, ten partial and four missing dedicated introductions/checks. All still need subject review. The four missing dedicated foundations are program state/control flow, recursion call state, prefix versus subsequence, and sort stability. Eight other foundations are partial.

The proposed dependency graph has **126 edges and no cycles**. It is a reviewable teaching proposal, not an assertion about an individual learner or a new runtime lock. The current unit order is not silently treated as prerequisite proof.

## Findings that affect pilot content

Three direct source inconsistencies are ready for follow-up: the Big-O check has an unrelated keyed answer label; the bubble-sort challenge asks for a copied output but scores O(1) in-place space; and jump-search prose says backward scan while its code advances forward. [Review gaps](review-gaps.md) provides exact lesson/block references, reproducible examples and acceptance gates. Additional questions cover ambiguous assessment options, indexing, graph assumptions, duplicate policies, code fragments and timing/mode declarations.

## Validation and maintenance

From the repository root:

```bash
python3 -B docs/learning/concept-map/validate_inventory.py
```

For an exact checkout of the pinned baseline:

```bash
python3 -B docs/learning/concept-map/validate_inventory.py --strict-baseline
```

The default validator checks every referenced content span and independently discovers the current source lesson/block IDs. If unrelated additions shift the file, it accepts only a uniquely relocated byte-identical span and reports checkout divergence; it never calls that file identical to the pinned baseline. Changed or missing referenced content, IDs or mappings fail. Strict mode additionally requires all eight baseline file hashes. The scanner supports the current literal helper calls and the pinned five-block `conceptLesson` factory; a new authoring pattern needs an explicit validator/inventory update.

The exact baseline passed strict validation. The parallel implementation checkout has changes in `packages/courseware/src/index.ts`; its 100 shifted content references were found unchanged, and the validator reported that divergence explicitly. Negative probes rejected duplicate concept IDs, a prerequisite cycle, a broken source span and a missing source file. No app, runtime model or package configuration was changed by this deliverable.

Coverage and hashes verify source consistency. They do not establish factual accuracy, accessible rendering, real audio playback, valid grading, delayed retention, transfer or a universal lesson duration. Private recall stays unscored; the four new prompt/rubric examples are documentation drafts and produce no learner history.
