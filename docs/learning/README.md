# Learning foundations

Brainbuilder's first microlearning implementation batch separates course activity from learning evidence and gives the existing algorithms material a reviewable concept structure.

| Foundation | Use |
| --- | --- |
| [Concept map and authoring inventory](concept-map/README.md) | Find the 56 candidate concepts, prerequisites, all 41 source lessons and two worked mappings |
| [Learning-evidence contract](evidence-contract/README.md) | Define what exposure, private practice, checked responses, delayed checks and application can establish |
| [Discovery preparation](../../research/discovery/README.md) | Prepare neutral interviews about work fluency, interview preparation and curiosity |
| [First batch and next work](../delivery/first-batch-2026-11-07.md) | Follow implementation, validation and the three new content defects |

The concepts and evidence semantics are reviewable candidates. Their validation tools check structural/reference and semantic consistency; they do not supply human educational approval, real learning outcomes or participant research. API/storage implementation remains in [BB-ENG-002](https://github.com/castlemilk/brainbuilder/issues/25) and related tasks.

The corresponding activity-completion change is [PR #71](https://github.com/castlemilk/brainbuilder/pull/71). It is a separate application branch so these source and product contracts can be reviewed independently.
