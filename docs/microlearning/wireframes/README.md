# Brainbuilder wireframe gallery

The three original PNG concept boards are saved in the [Brainbuilder Space image gallery](https://chatgpt.com/space/page_3d75c8071e8c8191852a5f5d33d75c1b). That page embeds all twelve screens alongside the complete interaction specification.

| Board | Screens | Design question |
|---|---|---|
| [01 Learn in the gaps](https://chatgpt.com/space/page_3d75c8071e8c8191852a5f5d33d75c1b) | Outcome setup, Today, one useful idea, recall before reveal | Can a learner start a useful short session with little planning? |
| [02 A lesson that travels with you](https://chatgpt.com/space/page_3d75c8071e8c8191852a5f5d33d75c1b) | Downloaded pack, listening, interruption recovery, return after a break | Can learning continue through changing attention and interruptions? |

## Original assets

The Space contains the complete original images. A large binary transfer to GitHub stalled during publication, so this commit uses the Space gallery as its image destination. No image was resized or altered. [wireframe-assets.json](wireframe-assets.json) records the original byte sizes and Git blob hashes for a later exact-byte repository transfer. Opening the Space requires access to that Space.
