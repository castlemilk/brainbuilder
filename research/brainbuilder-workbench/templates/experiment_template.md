# A testable product decision

**Status:** blank planning template. Thresholds below must be chosen before a real test; none are claimed as observed results.

## Decision and mechanism

| Field | Fill in |
| --- | --- |
| Hypothesis ID | Stable ID used in the ledger. |
| Target learner | Concrete segment and existing learning behavior. |
| Moment | Commute, waiting, walking, break, or other explicitly chosen context. |
| Desired outcome | A skill or idea the learner can explain or apply. |
| Mechanism | Why this design should change that outcome. |

## Test design

| Field | Fill in before recruiting |
| --- | --- |
| Format | Moderated prototype task, diary, concierge trial, randomized pilot, or pricing test. |
| Participants | Eligibility, recruitment channel, intended sample, exclusions, and likely bias. |
| Task/material | Comparable content and difficulty, especially for learning comparisons. |
| Duration | Immediate task plus a stated delayed check. |
| Allocation | How conditions are assigned; if not randomized, record the limitation. |
| Primary outcome | One main observable behavior, with a precise denominator. |
| Success condition | A predeclared practical decision threshold. |
| Rejection condition | A result that means stop or change direction. |
| Missing data | How interruptions, attrition, and missed follow-ups are reported. |
| Consent and contact | Actual approved process; this file does not authorize outreach. |
| Cost / effort | Participant time, recruitment, facilitation, and implementation. |

## Suggested questions and outcomes

| Question | Useful observation | What it cannot establish alone |
| --- | --- | --- |
| Can people begin during a short gap? | Unassisted start time and starting the intended lesson. | Long-term retention or willingness to pay. |
| Does interruption handling work? | Resume at the correct place after a realistic break. | Effectiveness of the teaching content. |
| Does retrieval add value? | Recall without hints after a stated delay, compared using similar material and time. | General efficacy from a small uncontrolled pilot. |
| Can learners use the concept? | Explain or solve a genuinely new example, scored using a prewritten rubric. | Transfer to every real-world setting. |
| Is an audio mode useful? | Voluntary use in an appropriate real context and reasons for switching modes. | That all commuters want voice interaction. |
| Is there paid demand? | A transparent, real, priced choice by eligible participants. | Recurring paid retention from one transaction or signup. |

## Results and decision

Record the numerator and denominator, missing participants, exact outcome definition, deviations from the plan, qualitative failures, and all conditions. Keep findings separate from the decision. State whether the original hypothesis was supported, rejected, or remains uncertain, and why.

Use a small pilot to expose failures and improve a test. If a broad learning-effectiveness claim or market-size estimate matters, plan an appropriately powered, representative, and reviewed study instead of extrapolating from an exploratory convenience sample.
